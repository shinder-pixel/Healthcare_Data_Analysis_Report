# # Healthcare_Data_Analysis_Report
# # Project Overview: 
#This project analyzes the financial performance of a healthcare center and evaluates healthcare provider performance using a comprehensive healthcare dataset.

#The objective is to transform raw healthcare data into meaningful financial, operational, and provider-level insights through data analysis and an interactive #dashboard.

#The analysis focuses on revenue, expenses, profitability, patient activity, provider efficiency, and trends over time to support data-driven decision-making.
